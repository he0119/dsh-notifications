# dsh-notifications：DSH 的会话提醒插件

[English](README.en.md) | 中文

给 DeepSeek Harness（DSH）加一层提醒：任务完成、意外中止、需要你回答、等待你审批时，用声音和系统弹窗通知你。DSH 窗口在后台、或者你在别的浏览器标签页里，同样会提醒。

要求 DSH **^0.2.0-rc.1**：0.2.x 的正式版与预发布版都算在内。开发与测试对照的是 **0.2.2-rc.2**。

## 安装

1. 打开 DSH 的插件管理器，选「添加插件」。
2. 填包名 `dsh-notifications`，安装，按提示重启。
3. 打开左侧「插件」页，找到 `dsh-notifications`，在它那一格里调整选项。

本地开发时可以直接装目录：装当前仓库的目录路径，或先 `pnpm run pack:release` 再用 `artifacts/` 里的 tarball。

## 能提醒什么

四类事件各自开关、各自选音色：

| 类别 | 什么时候提醒 |
| --- | --- |
| 完成 | 助手正常做完了这一轮 |
| 异常中止 | 出错、被限制等原因停下 |
| 需要答复 | 助手在等你回答问题 |
| 需要审批 | 有一项操作在等你批准 |

只提醒主会话（包括你手动分叉出来的会话）；子代理和团队成员不弹窗、不响铃，避免一次任务刷一屏通知。

## 提醒方式

- **系统弹窗**：从不 / 仅失焦 / 始终。选「仅失焦」时，DSH 在后台或浏览器切到别的标签页都会提醒。
- **提示音**：开关和音量独立于弹窗。开着的事件提示音在前台、后台都会响。
- **自定义音频**：每类事件都能导入自己的音频，也可以先用内置音色。自定义文件存在当前设备上，单个不超过 5 MiB，只播放前 8 秒，随时可以替换或移除。
- 点击通知回到对应会话。Windows 桌面版会用原生协议通知来恢复主窗口。

## 前提和限制

- 系统弹窗只在两类环境可用：Windows 桌面版 DSH；或者支持系统通知的桌面浏览器、Android Chrome／Edge 上的 HTTPS 页面。本机 `localhost` 页面也算安全上下文。
- 浏览器第一次使用要允许系统通知；提示音第一次可能被浏览器的自动播放策略挡住，点一次「试听」即可放行。
- 远程手机浏览器需要页面还在跑、连接还在。切到后台被系统挂起、锁屏、关掉浏览器，都可能收不到；这个插件不做离线推送。
- 首次发送 Windows 通知时，会为当前用户安装一个点击处理器（写在 `%LOCALAPPDATA%\DshNotifications`，并注册 `dsh-notifications` 协议），不需要管理员权限。它不改 DSH 自己的协议、快捷方式和图标。
- 和 Cyaness Tools 内置的通知识别符不同（插件行、接口命名空间、Worker 路径、协议各自独立），但同时启用两边会重复提醒，用哪个就只开哪个。
